# iHuman Lab Presentations

Two kinds of content live here:

- **Lab-authored tutorials** — full hands-on workshop decks, one top-level folder each (e.g. [`shasta-tutorial/`](shasta-tutorial/), [`mosaic-smc-tutorial/`](mosaic-smc-tutorial/)), each containing its own `presentation/` with a deck, setup guide, and facilitator run sheet.
- **Submitted talks and posters** — individual decks and posters built from [iHuman-Lab/templates](https://github.com/iHuman-Lab/templates), collected under `presentation/<name>/` and `poster/<name>/`. See [that repo's SUBMITTING.md](https://github.com/iHuman-Lab/templates/blob/main/SUBMITTING.md) for how to submit one.
