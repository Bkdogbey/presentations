# Covariance-steering course presentation

Quarto/reveal.js draft for Bennett Dogbey's MERO 5333 research-paper implementation project. The deck inherits the shared iHuman Lab theme, logo, and footer. Only deck-local files are added.

## Structure

The main presentation follows Introduction, Objectives, Approach, Simulation and Results, and Conclusion, followed by References. Seven backup slides develop the double-integrator model, stacked dynamics, moment propagation, expected cost, terminal LMI, risk allocation, and controller execution.

The Approach has seven slides: problem formulation; policy and stacked representation; mean/covariance prediction; expected cost and terminal distribution; Gaussian chance constraints; obstacle-region selection; final optimization and solution procedure.

## Draft status

The mathematical formulation and experiment plan are drafted. No controller optimization or Monte Carlo simulation has been completed as part of this presentation. All implementation results are explicitly pending. The published double-slit figure is labeled as a reference result and attributed to the original paper.

Before reporting a reproduction, specify initial/target distributions, cost weights, obstacle and region coordinates, face-risk allocation, numerical tolerances, and the region-search method. The paper reports a threshold of 1e-3, but its obstacle equation uses the threshold per face. A region-level budget must account for all face risks.

The first implementation stage uses fixed region schedules, followed by passage and switching-time enumeration. This is not automatically equivalent to unrestricted mixed-integer region selection. Document the schedule search and obtain instructor approval if a restricted implementation constitutes the final substantial portion. The exact terminal covariance constraint has a semidefinite representation; do not assume a generic mixed-integer SOCP solver can solve it unchanged.
